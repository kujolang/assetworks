# AssetWorks review — 2026-09-22

## Readiness verdict

AssetWorks is a useful local media evidence ledger, not a universally enterprise-ready media platform. This source review covered all seven `src/` modules, the entrypoint, launcher, schemas, existing tests, release scripts, CI configuration, and operational documentation. It is not an external penetration test or a certification. The local verification runtime is Kujo 1.4.0 on macOS; no fresh Linux/Windows or pinned-CI result is claimed here.

## Delivered improvements

- Dry runs and invalid mutations no longer create state directories or metadata.
- State and export paths reject existing symlinked ancestors before filesystem effects. Direct storage writes also preflight managed directories. Operators must supply canonical paths, including `/private/tmp` instead of macOS's `/tmp` alias.
- Calendar validation rejects impossible dates, including non-leap-year February 29.
- `--version --json` actually emits JSON; trailing unknown flags and missing flag values are rejected.
- Doctor and whole-state validation return failure with explicit incomplete codes when their 1,000-record inspection limit is reached. Per-ID validation remains available.
- Listing checks shared directory safety once instead of repeating ancestor checks for every record; each file retains ID, symlink, size, and JSON checks.
- The launcher resolves Kujo from PATH or `KUJO_BIN`, without a developer-specific absolute path. Validation passes its resolved runtime to contention testing and checks every worker's exit status.
- Presentation separates executable CLI behavior from library prototypes. The root entrypoint remains intentionally as the package/launcher target; no obsolete duplicate root implementation remains.

## Verification boundary

The validation gate includes all previous suites, the new review regression suite, JSON artifact parsing, entrypoint checking, CLI smoke tests, a 32-process distinct-ID contention check, runtime-boundary checks and `git diff --check`. New tests exercise absent-state dry runs, invalid mutation side effects, calendar edge cases, argument errors, symlinked ancestors, and 1,001-record incomplete inspection. Read coverage fixtures intentionally bypass storage writes; they are not durability evidence. Strong enterprise claims must wait for AW-01 through AW-09 evidence and a stated deployment model.

An isolated integrity probe also confirmed AW-01 and AW-03: a domain-valid edited record with its event deleted still returned successful validation, and forced export to its record path succeeded. The probe removed its temporary state. These are open local integrity gaps, not evidence of remote compromise.
